# 故障排除

| 提示 | 建議處理 |
| --- | --- |
| 找不到 ESP32 | 插緊 USB、換可傳資料的線、改插 USB 埠，確認 CH340／CP210x 驅動。 |
| 耳機未回應／PAGE_TIMEOUT | 耳機開機並靠近 ESP32，暫時中斷其他裝置連線；已配對者直接重試。 |
| USB 序列埠無法開啟 | 關閉 Arduino 序列監控或占用序列埠的程式，重新插入板子。 |
| 配對驗證失敗 | 確認沒有其他裝置搶連；持續失敗才取消本機配對，再進入配對模式重新配對。 |
| 未提供 LDAC | 確認支援 LDAC，檢查音質優先、多點連線設定。SBC／AAC 尚未提供播放。 |
| 有連線但無聲 | Windows 輸出與程式來源選相同 CABLE Input，檢查應用程式及耳機音量。 |
| 音訊斷續 | 先用 330 kbps、縮短距離並減少干擾；990 kbps 需要 2 Mbps 韌體。 |
| 電量無法取得 | 裝置未提供目前可讀取的回報，並不表示電量為零；XM4 目前實測也是如此。 |

錯誤提示位於各頁頂端，可展開原始錯誤碼。持續失敗可從「設定」匯出診斷紀錄。
紀錄可能包含裝置地址或埠資訊，公開分享前請移除不想公開的部分。
