ESP32 Audio — Windows development preview

This application sends Windows playback audio to compatible Bluetooth headphones
using an ESP32 bridge. LDAC is lossy. Only classic ESP32 boards with at least 4 MB
Flash are supported by the included firmware. Flashing replaces existing firmware;
the application creates a complete backup before writing.

The installer can install VB-CABLE by VB-Audio Software.
